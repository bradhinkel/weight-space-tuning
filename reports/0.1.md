# 0.1 Environment

## What was done
- Created a RunPod network volume (`61gtyoubem`, 200 GB, CA-MTL-1) and an A40 48 GB pod (`gr4byo6hup4lol`, $0.59/h). The L40 had no stock; the A40 is the same 48 GB class as the plan's A6000.
- `scripts/setup_pod.sh` builds two venvs: the main venv (torch, vLLM, transformers, PEFT, FLA, MCP, Anthropic SDK) and a separate bfcl-eval venv, because their pins conflict.
- `scripts/download.py` downloads Qwen3.5-2B, Qwen3.5-0.8B, xLAM-60k and BFCL and writes `env/revisions.json`.
- All versions and hashes are recorded in `env/lock.md`.

## Results
- Every download succeeded (`failed: {}`). xLAM first returned a 403 because it is gated. It worked after the human's access request was approved, under token user `bradhinkel`.

## Surprises or problems
- causal-conv1d won't build: the system CUDA toolkit is 12.8 and torch is CUDA 13.0. Transformers falls back to its PyTorch reference conv, which gives correct results but is slow. This is the main reason A.2 takes about 20 s/step.

## Cost
About 0.3 GPU-h for setup. No driver usage.
